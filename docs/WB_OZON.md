# WB и Ozon — рабочие правила менеджера

Ведёт сессия «AMURA — Менеджер WB/Ozon». Деньги (цены, реклама, акции) и любые изменения в кабинетах — только после «Да» владельца (в его чате или в очереди «На согласование» системы AMURA).

## Описания карточек

Правило владельца (31.10.2026):
- Описание пишется живым текстом для покупателя, ключевые запросы вплетены в предложения («крем для глаз от морщин», «крем для век», «крем вокруг глаз» и т. п.).
- Не писать отдельный список «Ключевые слова: …» — это против правил WB.
- Не писать «оригинал», «оригинальная косметика», «отправка со склада в Алматы», «декларация ЕАЭС».
- Только то, что есть в составе и на упаковке: без «быстро впитывается», «эффект через N недель» и прочих непроверенных обещаний.

## Ответы на отзывы и вопросы

Общие правила:
- Обращение по имени, если оно есть. На «вы», тепло и коротко: 2–4 предложения.
- Подпись: «Команда AMURA».
- Только правда из описания и этикетки. Не обещать лечебный эффект, не писать «лечит», «убирает акне», «клинически доказано».
- Не спорить, не обвинять покупателя, не просить изменить оценку.
- На негатив — извиниться, предложить решение и написать, что делать дальше (чат WB/Ozon, возврат по правилам площадки).
- Не писать телефоны, ссылки, Instagram и сайт: площадки за это наказывают.
- Ответ — в течение суток.

## Реклама — Anua PDRN 100, 60 мл (00615)

Предложение. Запуск только по «Да» владельца и только когда карточка опубликована, цена стоит, есть остаток.

Исходные: цена на WB 13 500 ₸, себестоимость ~6 005 ₸, план ДРР на старте 10% → на рекламу не больше ~1 350 ₸ с продажи.

**WB**
- Тип: поиск, оплата за клики (CPC): платим только за переход в карточку.
- Ключевые фразы: «крем pdrn», «anua pdrn», «крем с пдрн», «крем для лица увлажняющий», «крем с гиалуроновой кислотой», «корейский крем для лица». Минус-фразы: «сыворотка», «тонер», «пэды», «маска».
- Ставка: из расчёта ~3% конверсии клика в заказ допустимо до ~40 ₸ за клик (1 350 × 0,03). Старт — минимальная ставка WB по фразе, поднимать только при показах ниже 1-й–2-й страницы.
- Бюджет: 3 000 ₸ в день, тест 14 дней (≈ 42 000 ₸ максимум). Цель — 2–3 заказа в день.
- Через 7 дней: смотрим факт ДРР в калькуляторе. Выше 15% — снижаем ставки и чистим фразы; ниже 8% — можно добавить бюджет.

**Ozon**
- Тип: «Оплата за заказ»: платим только за оформленный заказ.
- Ставка: 10% от цены. Без риска потратить деньги без продаж.

**Отзывы на старте.** Без отзывов конверсия ниже. Первые отзывы — платный сервис площадки («Отзывы за баллы» на WB): предложу отдельно, только с согласия владельца.
