- **MCP-сервер системы AMURA** (24.10.2026): свой MCP-сервер на admin.amura.kz, чтобы агенты и владелец (приложение Claude на телефоне) спрашивали систему готовыми командами, а не через базу Render или репозиторий.
  Зачем: один вход для всех сессий с правами по ролям (сюда же войдёт ключ склада); вопросы с телефона («сколько заказов не подтверждено?», «кто ждёт ответа?»); живые блоки в «Сводке AMURA» (дашборд берёт данные из подключённого сервера).
  Не заменяет МойСклад (учёт там, у него свой сервер) — только то, чего в МойСклад нет: заказы с сайтов, оплаты Kaspi/Freedom, переписка, витрина, источники.
  План: этап 1 — только чтение, 6–8 команд (заказы с сайтов, чаты без ответа, статусы оплат, источники заказов, товары без фото/цены, сводка дня), вход по логину системы AMURA, телефоны и адреса клиентов по умолчанию скрыты, модуль включается в «Настройках»; оценка 1–2 дня. Этап 2 — действия (черновик ответа клиенту, смена статуса заказа), каждое только после «да» владельца.
  Окупается, если владелец хочет спрашивать систему с телефона и видеть живую сводку; для одних сессий хватает нынешнего доступа.
