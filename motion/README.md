# AMURA Motion — бренд-файл роликов

Моушн-ролики AMURA о косметике: увлекательно рассказать о товаре так, чтобы человек **остановился** в ленте, **досмотрел** и **пошёл заказывать** по артикулу.
Всё, что здесь описано, уже есть в коде `motion/kit` — ролики собираются из описания товара, а не рисуются с нуля.

## Правила (обязательно)

1. **Зацепка за 1 секунду.** Первый кадр — вопрос-боль крупно («Поры расширены?»), без логотипа и вступлений. Слово влетает «ударом».
2. **Смена картинки каждые 1,5–2 секунды.** Новая плашка, цифра, чип или сцена — глазу не на чем заскучать.
3. **Картинка идёт за голосом.** Каждое ключевое слово голоса появляется на экране в тот же момент (время по словам озвучки, `@слово`).
4. **Цену не показываем и не называем** (решение владельца). Только товар, его польза и артикул.
5. **Концовка одинаковая:** артикул крупно → «также в описании» → «ссылка на магазин — в шапке профиля» → артикул набирается в поиске и находится товар.
6. **Только правда о товаре:** проценты, составы и эффекты — из описания и этикетки. Без «вылечит», «навсегда», выдуманных отзывов и рейтингов.
7. **Розница — amura.kz**, опт — отдельные ролики для opt.amura.kz (по решению владельца на каждую кампанию).
8. **Публикация и реклама — только после «да» владельца.**

## Стиль

| | |
|---|---|
| Формат | 1080×1920, 30 к/с, 20–35 с (Reels, TikTok, Shorts) |
| Фон | глубокий зелёный AMURA `#071F17 → #13503B`, свет из центра, сетка «пор», зерно |
| Акцент | салатовый `#D7EA4A` — цифры, выделенные слова, свечение, кнопки-плашки |
| Фирменный зелёный | `#1F6A50` — кнопка «ссылка в шапке профиля» |
| Второй акцент | латунь `#B89760` — редко: «премиум», щит, звезда |
| Красный | `#C2412D` — только «плохо»: «было», зачёркивание |
| Заголовки | **Unbounded 800** — крупно, плотно |
| Текст, чипы, субтитры | **Manrope 800** |
| Товар | вырезан с фона (`tools/cutout.py`), с тенью и салатовым свечением сзади |
| Безопасные зоны | верх 250 px — бренд; низ ниже 1500 px закрывает интерфейс Reels — там ничего важного. Субтитры — на 1440 px |

## Фишки (`kit/kit.js`)

| Название | Код | Где применять |
|---|---|---|
| **Удар** | `AM.slam`, `AM.slamWin` | слово влетает из крупного плана с размытием + тряска + вспышка. Зацепка, главные слова |
| **Взлёт** | `AM.rise` | товар вылетает снизу с перелётом. Появление товара |
| **Блик** | `AM.sweep` | полоса света пробегает по флакону. Сразу после «взлёта» |
| **Свечение + Кольцо** | `AM.glow`, `AM.ring` | салатовый ореол за товаром и расходящееся кольцо |
| **Парение / Покачивание** | `AM.float`, `AM.sway` | товар «дышит», пока на экране — кадр никогда не замирает |
| **Влёт сбоку** | `AM.slide` | карточки фактов, сравнения |
| **Поп** | `AM.pop` | чипы-выводы («плотнее», «глаже»), плашки |
| **Счётчик** | `AM.count` | целые числа тикают от нуля (дни, проценты) |
| **Цифры по голосу** | `AM.digits` | артикул появляется цифра за цифрой под голос |
| **Набор** | `AM.type`, `AM.caret` | артикул печатается в строке поиска |
| **Маркер / Зачёркивание** | `AM.marker`, `AM.strike` | салатовая подложка под словом; красная черта «было» |
| **Капля** | `AM.drop` | капля падает и расходится лужицей — текстура |
| **Пульс** | `AM.pulse` | кнопка-призыв «ссылка в шапке профиля» |
| **Поры** | `AM.dots` | фон зацепки: сетка точек наезжает |
| **Караоке-субтитры** | `AM.karaoke` | фраза по 2–4 слова, текущее слово салатовым — смотрят без звука |

## Переходы

| Название | `in:` | Когда |
|---|---|---|
| **Зум-вспышка** | `zoom` (по умолчанию) | обычная смена сцены |
| **Свайп** | `whip` | «а теперь сравним», смена темы |
| **Шторка** | `wipe` | салатовая диагональ — переход к составу/фактам, акцентный момент |
| **Ирис** | `iris` (+ `x`, `y`) | новая сцена раскрывается кругом из точки — текстура, «внутри» |
| **Склейка** | `cut` | без эффекта |

Не больше 3 разных переходов в одном ролике; «Шторку» — один раз.

## Звук (`tools/mix.py`)

Звуки фишек ставятся **автоматически** по меткам из анимации: удар, «вжух» (переходы и взлёт), свист (влёт сбоку), «поп» (чипы), щелчки (цифры и набор), звон (блик), «бульк» (капля).
Подложка — бит 120 BPM с мягким аккордом; под голосом бит приглушается. Громкость ролика −14 LUFS.

## Структура товарного ролика (`kit/product.js`)

| Сцена | `type` | Что показывает |
|---|---|---|
| Зацепка | `hook` | 1–3 вопроса-боли «ударом» |
| Знакомство | `reveal` | товар «взлетает», блик, подпись-чип |
| Сравнение | `compare` | «было → стало» (ретинол → ретиналь, обычный → с пептидами) |
| Состав / факты | `facts` | товар + 2–3 карточки с процентами + чипы-эффекты |
| Текстура и способ | `texture` | капля, шкала «лёгкое ↔ плотное», шаги ухода |
| Мысль | `statement` | одна фраза крупно, слова в `<mark>` выделяются маркером |
| Призыв | `cta` | артикул, «в описании», «ссылка в шапке профиля», поиск по артикулу |

Голос: 70–110 слов, на «вы», живо, темп ×1.1–1.2. Шаблон: *боль → знакомство → почему работает → состав → как наносить → артикул и где купить*.

## Как сделать ролик (для Монтажёра)

1. **Папка:** скопировать `reels/celimax-01330` в `reels/<бренд>-<артикул>`.
2. **Товар:** фото из карточки → `python3 motion/tools/cutout.py фото.jpg reels/<папка>/bottle.png --crop x1,y1,x2,y2` (печатает `ratio` для `data.js`).
3. **Текст голоса** по шаблону выше — факты только из описания товара (`catalog.json`, поле `desc`).
4. **Озвучка:** ElevenLabs или Virale (голос `EXAVITQu4vr4xnSDxMaL`, ru) — скачать mp3 и JSON выравнивания, затем
   `python3 motion/tools/align.py reels/<папка> голос.mp3 выравнивание.json --tempo 1.15 --fix "Селимакс=Celimax" --join "ноль один три три ноль=01330"`.
5. **Сцены:** в `data.js` описать сцены и время каждой — словом голоса: `at: '@Пантенол'`, `'@Пантенол+0.3'`, `'@слово>'` (конец слова).
6. **Проверка кадров:** `node motion/render.js reels/<папка> --snap 1,5,12,20,30` → `snap_*.jpg`.
7. **Рендер:** `node motion/render.js reels/<папка>` → `out.mp4` (кадры, звук, сборка — около минуты на 30 с).
8. Готовый ролик — в Google Drive «AMURA — Креативы / 2. Ролики» и владельцу на «да». Голос и видео в git не храним.

Пример: `reels/celimax-01330` — Celimax Retinal Shot First Essence Toner.
