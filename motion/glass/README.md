# AMURA Glass — стиль роликов

Решение владельца 20.10.2026, образец — reel @faris.shukurov. Старый моушн-стиль удалён (PR #342).

**Как выглядит:** фон — серебристо-графитовый «хром» с изогнутыми лентами и тонкой радужной призмой, почти статичен. Элементы — стеклянные карточки (Liquid Glass): матовое стекло, размытие фона, тонкая светлая обводка, мягкая тень. Белый текст, шрифт Inter. Без ярких цветов.

**Ритм (10–15 с):**
1. 0–3 с — текст-хук печатается по буквам по центру (щелчки клавиш).
2. «Динь» — из центра появляется стеклянная карточка с настоящим фото товара.
3. Карточка вытягивается в список 1–2–3, пункты появляются по одному («пинг»). Только правда из описания товара.
4. Список сжимается в стеклянную «таблетку»: AMURA + amura.kz · артикул («поп»), под ней «ссылка на магазин — в шапке профиля». Музыка затихает.

Цену в роликах не показываем.

**Файлы:** `glass.css` — фон, стекло, текст; `glass.js` — анимации (`G.type`, `G.A`, `G.show`, `G.cue`); `render.js` — кадры → mp4 1080×1920, 30 к/с; `sfx.py` — звуки синтезом (щелчок, динь, пинг, поп, вжух) + тихий бит 100 BPM, без чужой музыки.

**Новый ролик:** скопировать `reels/celimax-glass-00148` в `reels/<бренд>-glass-<артикул>`, поправить `prep.py` (id фото) и тексты в `index.html`.
`python3 motion/reels/<папка>/prep.py` → `node motion/glass/render.js motion/reels/<папка> --snap 2,5,8,11` (кадры-проверки) → `node motion/glass/render.js motion/reels/<папка>` → `out.mp4`.
Медиа в git не храним. Публикация — только после «да» владельца.

**Голос и музыка:** голос — ElevenLabs (платно, только по просьбе владельца), файл `voice.wav` в папке ролика; под голосом музыка приглушается сама (`sfx.py`). Музыка — свой бит из `sfx.py`.
