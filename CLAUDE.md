# AMURA — правила работы

- Магазин: `index.html` (GitHub Pages, amura.kz) — оптовый. Розничный сайт amura.kz/shop — тот же `index.html` в режиме розницы: `shop/index.html` собирает `make_shop.py` (и GitHub Action), вручную не править; розничные заказы помечены «Заказ с розничного сайта». Панель: `admin.html` + Flask (`app.py`, `admin.py`, `order_hook.py`, `inbox.py`, `wa.py`, `team.py`, `push.py`) на Render, admin.amura.kz.
- Делать сразу, не спрашивать «сделать ли»: изменение → проверка → коммит → PR → merge → деплой на Render.
- **Любое изменение панели делать одновременно для телефона и для компьютера.** Подразделы — вкладки `.seg` вверху и на телефоне, и на компьютере (на компьютере — строкой с подчёркиванием, как в кабинете WB); в боковом меню `aside` только разделы, блоки `.subs` скрыты. Окна `.eo`: на телефоне — снизу, на компьютере — на весь экран. Проверять обе ширины (390px и 1280px).
- Интерфейс — на русском, суммы в тенге без копеек.
- Время в МойСклад — московское (UTC+3), у магазина — Алматы (UTC+5).
- **Новые крупные разделы — подключаемые модули** (Склад, Финансы, Касса и т.д.): владелец включает/выключает их в настройках, выключенный модуль невидим и ни на что не влияет; источник данных модуля переключается «МойСклад / наша база». Касса — обязательный модуль с фискализацией через онлайн-кассу/ОФД Казахстана (провайдер подключаемый). Подробный план переезда с МойСклад — `docs/MIGRATION.md`.
- Маркетплейс для других продавцов — отложенная задумка, решения и открытые вопросы в `docs/MARKETPLACE.md` (не строить, пока владелец не скажет).
