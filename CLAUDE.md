# AMURA — правила работы

- Магазин: оптовый сайт — `opt/index.html`, открывается на **opt.amura.kz** (сервер `opt_site.py` берёт файлы с GitHub Pages). Розничный сайт **amura.kz** — тот же `opt/index.html` в режиме розницы: корневой `index.html` и `shop/` (старый адрес — переадресация, юр. страницы `shop/legal/`) собирает `make_shop.py` (и GitHub Action), вручную не править; розничные заказы помечены «Заказ с розничного сайта». Оптовиков, заходивших на amura.kz раньше, розница сама переводит на opt.amura.kz с корзиной и входом. Панель: `admin.html` + Flask (`app.py`, `admin.py`, `order_hook.py`, `inbox.py`, `wa.py`, `team.py`, `push.py`) на Render, admin.amura.kz.
- Делать сразу, не спрашивать «сделать ли»: изменение → проверка → коммит → PR → merge → деплой на Render.
- **Любое изменение панели делать одновременно для телефона и для компьютера.** Подразделы — вкладки `.seg` вверху и на телефоне, и на компьютере (на компьютере — строкой с подчёркиванием, как в кабинете WB); в боковом меню `aside` только разделы, блоки `.subs` скрыты. Окна `.eo`: на телефоне — снизу, на компьютере — на весь экран. Проверять обе ширины (390px и 1280px).
- Интерфейс — на русском, суммы в тенге без копеек.
- В общении с владельцем панель (admin.amura.kz) называть **«система AMURA»**, не «панель» и не «админка».
- Время в МойСклад — московское (UTC+3), у магазина — Алматы (UTC+5).
- **Учёт ведём в МойСклад, свою систему учёта не строим** (решение владельца 17.10.2026). Система AMURA — кабинет продавца, как на WB/Ozon/Kaspi: заказы, оплата, сообщения, витрина сайта (товары, баннеры), доставка, источники/блогеры. Разделы, дублирующие МойСклад (своя база, склад, финансы), спрятаны; меню — 5–6 разделов. Переезд с МойСклад (`docs/MIGRATION.md`) остановлен. Новые разделы — подключаемые модули (владелец включает/выключает в «Настройках», выключенный невидим). Касса — касса Kaspi владельца.
- Новый дизайн системы AMURA — выбор владельца записан в `docs/DESIGN.md`; дизайн не менять, пока владелец не скажет начинать.
- Скилл вкуса `.claude/skills/design-taste-frontend` (Taste Skill, добавлен по слову владельца 21.10.2026) — для новых страниц и для редизайна по слову владельца. Утверждённое (`docs/DESIGN.md`, `docs/CARDS.md`, нынешний вид сайтов и системы AMURA) важнее его правил; сам по себе он не повод перекрашивать существующее.
- Карточки товаров (инфографика) — утверждённый дизайн и шаблон запроса в `docs/CARDS.md`; ролики — новый стиль по образцу владельца (reel @faris.shukurov, 19.10.2026; старый моушн-стиль `motion/kit` удалён по решению владельца 20.10.2026), ASMR-уход — `motion/asmr`. Их делает сессия «AMURA — Дизайн-монтажёр».
- Маркетплейс для других продавцов — отложенная задумка, решения и открытые вопросы в `docs/MARKETPLACE.md` (не строить, пока владелец не скажет).
